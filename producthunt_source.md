## Tin hieu ve su thay doi dinh vi

Chuoi launch tren Product Hunt cho thay mot huong phat trien nhat quan:

`next-edit autocomplete -> AI Code Editor -> agent trong IDE -> agent tren nhieu thiet bi -> multi-agent va model rieng -> visual editing -> model frontier rieng -> mobile-native agents`

- **Giai doan tinh nang:** Cursor ban dau nhan manh kha nang autocomplete co the du doan lan sua tiep theo.
- **Giai doan san pham:** Thong diep "The AI Code Editor" dua AI thanh lop trai nghiem chinh cua IDE.
- **Giai doan agent:** Cursor 1.0 va Agents dua AI tu goi y code sang tu thuc hien, review va ghi nho cong viec.
- **Giai doan nen tang:** Cursor 2.0 ket hop model rieng, nhieu agent song song, browser va cac be mat tuong tac moi.
- **Giai doan model va phan phoi:** Composer 2/2.5 day manh nang luc model rieng, trong khi Cursor for iOS dua agent den thiet bi di dong.

Day la gia thuyet timeline de nhom kiem tra cheo voi Cursor Changelog, blog cong
ty va phat bieu cua founder; khong nen xem rieng Product Hunt la bang chung du
de ket luan ve pivot.
